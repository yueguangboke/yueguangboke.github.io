博客站长务必要养成的好习惯

2017-2-25 22:38:23 | 作者: 投稿 | 分类: 网站建设 | 评论: 2 | 浏览:

摘要：俗话说“没有规矩，不成方圆。”对于我们博客站长来说，好的习惯可以成就一个博客，坏的习惯当然也可以毁掉一个博客。所以要想在当今复杂多变的互联网世界中立足，博客站长必须有一个好的习惯，本文将介绍博客站长务必要养成的好习惯。

1、文章内使用图片的好习惯

大家都知道一篇图文并茂的文章用户体验是最好的，所以文章内插入图片应该是大家经常要做的一件事儿吧，那么这个简单的工作看似简单，其实做起来想做好就必须要有好习惯，要不无论是用户体验、搜索引擎收录、关键词排名上都会有不小的麻烦。

这是最简单的博客文章引用图片的办法，效率很高，可行性也很强，带来的后果是随着时间的推移，这篇有外链图片的文章受制于外链服务器可能会拖慢你网站的载入速度，如果对方开启了“防盗链”那么你将面临着整篇“红叉叉”的文章，时间稍旧。你想修复也无从下手了，这样一篇文章无论是用户还是搜索引擎都不会有过多的关注的。再有的就是外链图片仅仅是个链接，图片内容是你无法控制的，如果变更成不和谐的图片，被关站肯定避免不了。就算图片内容没问题，那要是人家加上了“水印”，是不是在告诉你的用户，你的文章都是转载和抄袭复制的。一篇文章就算只有一张外链图片，那么1000篇文章就是1000个外链引用，你的主机净忙着处理图片链接，执行效率就得降低，整体博客网站速度就会卡顿缓慢。

就算上述问题都不会发生，那么等几年你的博客人气、流量都有增长（这时你的博客如果依然速度如初，请跳过此段就当我啥也没说）主机需要升级或者是加速优化，那这些外链图片将会变成“噩梦”，如果外链图片还失效了，那修复的工作量一定会让你退却的，最简单的修复就是取消所有文章内失效图片，图文并茂的文章“图”是没有了。大家可参考【新年期间耗时七天，手动清理文章内失效图片！】一文，这是我自己的亲身经历。

那么好习惯是什么呢？好习惯就是手动上传插入图片，每篇文章的图片无论多少都要认真对待，这样的好习惯下的博文，多年后再读起来依然如故，无论是用户还是搜索引擎都会青睐有加的，提升博客网站权重和关键词排名有的时候往往都是这些被我们遗忘的文章会有意外惊喜。我的真实经历【《芈月传》带来的搜索流量！意外中的收获！】

有很多新手站长们喜欢在插入图片时插入原图，从来不考虑图片在文章中大小比例是否合适，1024X768和500X375缩放比例图片对文章载入时间的影响还是很明显的，一篇文章多过三幅尺寸宽度大于800的图片载入速度就会慢下来，如果每篇文章都有这种可能，那么你的服务器能承受同时在线人数将会大幅下降，一旦同时访问人数增多服务器负暂超高“宕机”几乎是必然的。这么大的图片文件体积必然都在100-200KB以上，这对 CDN 、网站主机出口流量都是一个很大的消耗，效率低、流量消耗过大必然增加运营成本。因为载入速度慢，用户流失率也会很高，可以说是得不偿失。

那么好习惯是什么呢？好习惯就是在上传图片时记得设置这个图片要“链接到媒体文件”。

不要小看这个设置，因为有了这个设置后在“主题支持”或者“插件”帮助下可以利用 WordPress 的“图片暗箱”（所谓的暗箱，就是点击小图片弹出窗口并显示大图片）功能实现自动缩放为指定的图片比例，只有在客户点击此图时才会显示高清大图，有效的加快了文章的载入时间。

WordPress 可以通过代码设定默认图片上传后自动链接至媒体文件（具体可百度谷歌）， WordPress 主题和第三方插件也可以实现，主题比如：知更鸟 Begin 主题等。插件比如：我爱水煮鱼 WPJAM-Basic等。

插入图片的时候设定一个合适的缩放比例尺寸，尽量不要原图插入。

对于已经原图插入的文章，目前最好的办法明月认为就是启用七牛云，利用七牛云存储的“图像处理功能”来自动缩小文章内图片的比例尺寸为指定的尺寸，具体方法可参考【分享几个有关七牛云和评论邮件的实用代码】一文

2、编辑文章采用文本源的好习惯

很多新手站长们喜欢“复制”、“粘贴”这样来发布文章，虽然这样效率非常的高，但是这是一个很不可取的方式。因为简单的“复制”虽然看似文字、排版格式、图片都成了自己的文章内容，但是对于浏览器和搜索引擎来说除了文字、排版格式、图片这些还有大量的HTML&CSS代码，对于浏览器来说这会降低解析的兼容性（因为复制的代码永远都是不完整的），对于搜索引擎来说这是一篇臃肿杂乱的文章、抄袭甚至是采集的文章。那么大家想想这样的结果真的是你想要的吗？如果这个博客大量的文章都是这样的，试想想会有多好的网站权重、收录量、关键词排名呢？

当然，有人会说“原创”才会有好的排名、收录，但现实是并非如此，100篇原创抵不上一篇转载、排版完美的老文章，这事儿几乎天天都在发生。这篇很能说明这点的，“老司机”站长一定不会怀疑吧？

那么好习惯是什么呢？好习惯就是使用文本格式粘贴到编辑器里重新整理排版、分段、设定标题、手动插入图片，转载的文章有必要这么麻烦吗？很有必要，因为认真对待每一篇文章，哪怕是转载抄袭的都要认真的对待，这其实就是认真的对待每一个访问你博客的用户，转载的文章也要让用户体验做到最好，最终用户记下的就是你的博客而不仅仅是某一篇文章。推荐大家阅读【如何用 WordPress 写出一篇“好看”的文章】一文，我是受益良多。

3、尽量缩减 WordPress 使用插件的数量

很多人不使用 WordPress 都说是因为 WordPress 过于臃肿、主机占用资源过高、执行效率低下等等，其实这是一个很大的误解， WordPress 拥有全球38%的占有量，所以必须要有很好的兼容性和可扩展性所以就必须有比较全面的开放性，本身 WordPress 的代码质量是没得说的【WordPress代码质量怎么样？】，占用资源过高、执行效率低下罪魁祸首几乎都是“插件”造成。插件制作者水平良莠不齐，代码质量有好有坏，众多插件里大部分都是针对国外 WordPress 使用者的，国内 WordPress 主机使用受制于“墙”的存在必然会有卡顿、占用资源现象的，所以使用过多的插件绝对是得不偿失的。

再加上新手站长们对 WordPress 的不了解使用插件都是看到喜欢的就下载上传安装，从来没有考虑过“安全因素”，很多非官方渠道获得的插件都有后门、木马植入，一旦上传安装激活主机就被利用和控制，经常出现各种不知原因的宕机、卡顿，甚至会出现博客被挂黑链等等，可以说 WordPress 的最大的安全隐患大部分都是来自非官方渠道的插件或者破解版主题的。很多博客站长反应的博客速度慢都是因为插件安装过多造成的，特别是SEO插件，这些插件几乎都是落伍的，不用反而比用了效果好。

那么好习惯是什么呢？好习惯就是能用代码实现的功能就尽量使用代码，必须使用插件的时候一定要到 WordPress 官方插件库里查找和安装（ WordPress 后台插件——安装插件既可打开官方插件库），并且还要看看这个插件最近更新时间，超过一年以下的就不要使用了，兼容性和稳定性都不会很靠谱的。总之，尽量把插件使用量控制在个位数最好。

4、技术难题多请教百度、谷歌的好习惯

玩博客一定会碰到自己无法解决的技术难题，这时候不是到处问别人，因为主机环境、插件使用、主题不同的情况下就算是问别人也不见得就能得到有效的答案，如果自己很小白的话还会发生答非所问、问非所答的尴尬，所以尽量少问，就算要问也得是有“专业性”的问，避免张嘴就是只管问不思考，这样会吓跑高手的，真的，再高的高手都怕小白“十万个为什么”式的“问”，这真的会抓狂的有没有！

那么好习惯是什么呢？好习惯就是利用好搜索引擎，现在已经是一个信息高度对称的时代了，互联网上是无所不有的，百度、谷歌可以解决掉你大部分的疑难杂症。有人会说我不会搜或者是搜不到？这个其实就是作为一个博客站长必须要过的“坎儿”，因为以后你跟搜索引擎打交道的日子会很长很长，从自己“问题”里找出“关键词”并搜索到自己所需的结果就是一个认知搜索引擎的过程，有了这个过程你才能知道如何创作出搜索引擎需要的内容来，所以无论是当前还是以后，多用用搜索引擎吧，亲！

5、有评必回和必回访的好习惯

这个，其实是个老生常谈的话题了，明月可以说已经发文说过多次了，今天在这里又拿出来说无非是强调一下其重要性而已，一个没有互动的博客是没有生命力的。想获得这个至关重要的生命力只有自己的勤奋和坚持，坚持走访评论、坚持回评回访以达到让人注意到你，开始关注你的目的。平凡的我们只能从这些平凡的坚持来获得我们应得的尊重。

那么好习惯是什么呢？好习惯就是自己博客收到的评论一定要及时的查看和回复，让每一个评论者都能感受到你在认真对待，没有人不愿意获得尊重的。所以，自己博客的评论邮箱提醒一定要开启，以便获得有新评论的提醒，当然手机接收邮件现在也不是个“事儿”了，推荐使用QQ邮箱作为接受提醒的主要邮箱，原因很简单因为QQ普及率太高了，QQ邮箱的客户端也很完善，微信、QQ等等众多腾讯应用都可以接受邮件，再配合 WordPress 手机客户端，还可以做到随时用手机回复博客上的评论。细心的站长们应该有发现明月回复评论的速度几乎是实时的，原因就在于此。

最后说个题外话， WordPress 的采用邮件作为互动的主要通信工具这跟西方人习惯有关系，老外用短信的很少，用邮箱的可以说几乎每个人都在用，这也是为啥支持“Push Mail”的黑莓（BlackBerry）手机在美剧里出镜率很高的原因（当然现在很多都是苹果手机了，苹果官方的“Push Mail”可惜国内是体验不到的）

俗话说“没有规矩，不成方圆。”对于我们博客站长来说，好的习惯可以成就一个博客，坏的习惯当然也可以毁掉一个博客。所以要想在当今复杂多变的互联网世界中立足，博客站长必须有一个好的习惯，那么如何养成好习惯呢，下面明月就给大家带来养成好习惯的经验。

【态度】记得有人说过“你的态度决定踮碚牢邗了你的高度”；所以做一件事之前，一定要有一个好的态度。同样，养成习惯也是这样的，所以首先要有一个好的态度。

【恒心】养成一个好的习惯，要有一个好的坚持，要有一颗好的恒心，不断坚持，一般一个好的习惯坚持21天就能养成了。

【毅力】毅力是做成一件事非常重要的。特别是养成习惯的时候，有很多阻碍和诱惑，这时候毅力就可以帮助你度过难关。

【规矩】“规矩”是非常重要的，只有有了条条框框，才能更好的去养成习惯，养成习惯才是一个好的习惯。

【坚持】也许会是一个让人习惯养成的一个好的方法，不断努力，不断提高，不断突破，在收获胜利感的同时，带来好的习惯养成。
