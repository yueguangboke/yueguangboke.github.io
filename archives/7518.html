GitHub Pages搭建个人网站指南

2025-10-20 15:35:0 | 作者: 月光 | 分类: 网站建设 | 评论: 0 | 浏览:

怎么免费搭建个人网站是个老生常谈的话题了，对于一个纯HTML网站来说，使用GitHub Pages来搭建，目前来说是一个首选方案，其特点是免费、稳定、高速、可拓展性强。本文将详细讲述GitHub Pages搭建网站的教程。

一、网站地址和账号

搭建 GitHub Pages 需要先注册 GitHub 账号：前往 GitHub 官网完成注册，注册的用户名就是子域名的名称。

Github支持自定义域名，可将自己注册的域名做为网站域名，如果不付费注册域名的话，也可以免费使用Github提供的子域名。

用户网站主站的站点的域名为：仓库名必须为 用户名.github.io，全局唯一，对应根域名站点。

用户项目站点（子站）：任意仓库均可开启，站点地址为 用户名.github.io/仓库名，适合搭建项目文档站。

二、基础环境搭建与首次部署

1. 创建仓库

登录 GitHub 账号，点击首页右上角「+」号，选择 New repository 新建仓库：

仓库名称严格填写：你的GitHub用户名.github.io（必须和账号用户名完全一致，大小写敏感），仓库权限选择 Public（公开）（私有仓库无法免费启用 Pages 服务），点击底部 Create repository 完成创建。

2. 本地环境

本地环境有很多选择，推荐使用 VS Code + Git 组合，在 VS Code 中可以用 AI 来创建一个网站，例如，输入提示词：创建个人网站，然后输入关于个人网站的要求，AI生成页面之后，点右侧菜单“源代码管理”- 发布到Github。这种通过 VS Code 发布 Github 的方式适合少量HTML文件，不熟悉 git 命令行的用户。

如果有现成做好的网站，HTML文件数量很多的话，建议用 git 命令行来操作。

克隆仓库到本地：

git clone https://github.com/用户名/用户名.github.io.git

cd 用户名.github.io

3. 基础文件结构与首次提交

网站默认入口文件为 index.html，将你做好的网站html文件全部复制过来。

使用下面的命令提交并推送网站的代码：

git add .
git commit -m "init: upload all html files"
git push -u origin main

返回仓库主页，点击顶部导航栏 Settings（设置），左侧侧边栏下滑找到并点击 Pages 选项，在 Build and deployment 部署区域，设置参数，选择 Deploy from a branch，选择 main 分支，选择 / (root) 根目录，点击右侧 Save 保存配置。

等待一会儿之后，访问 https://用户名.github.io 即可看到个人页面。

4. 批量修改

对于已经存在的文件，先通过pull命令将文件拉下来

git pull origin main

之后，通过各种方法来修改本地html文件，批量修改好了以后，通过下面的命令批量上传到github上去。

git add "*.html"
git commit -m "refactor: fix bug"
git push origin main

三、自定义域名

默认二级域名较长，绑定自定义域名后，网站更专业、更具个人标识，GitHub Pages 免费支持 HTTPS 加密。

购买域名推荐用Cloudflare。

添加 CNAME 记录：在域名 DNS 管理中添加 CNAME 记录，主机名为 @ 或 www，指向 用户名.github.io。

仓库配置：在 GitHub 仓库设置中启用「Custom domain」并输入域名。勾选 Enforce HTTPS，开启全站加密访问。

等待几分钟解析生效，即可通过自定义域名访问网站。
