Python之父：我们能为中国的“996”程序员做什么？

2019-4-9 17:15:49 | 作者: 月光 | 分类: 业界动态 | 评论: 22 | 浏览:

一周前，当 996.ICU 的 GitHub repo 火速在互联网广泛传播时，Python 之父 Guido van Rossum 就在其推特转发了南华早报关于中国程序员 996 工作制的新闻报导，认为 996 工作制是不人道的，并且 star 了 996.ICU 的 GitHub repo。

日前，Python之父再度为“中国程序员996工作制”发声，他在 Python 的官方论坛上发表了一篇名为“Can we do something for 996 programmers in China?”的帖子，帖子内容主要是 Guido 表示自己在推特转发那则关于 996 的新闻后，其推特的内容流目前基本全都是关于这个问题的讨论。他问到，一周前一些中国程序员创建了996.icu抱怨恶劣的工作条件，现在该网站已被各种中国浏览器禁止访问，我们怎么样才能帮助中国开发者？

对此，Python核心开发人员Senthil提出3条建议：

a）让大家都知道存在这种“剥削”劳动力的现象，并在听到这些事时能表现出同理心。

b）列出执行这种工作制的公司，拒绝与他们开展业务合作，这是施加压力的最有效方式。

c）拒绝接受这些公司对 Python 的赞助。 

“996.ICU”，其意为“工作996，生病ICU。”据该网页介绍称，这是中国程序员的讽刺说法，意味着按照“996”工作时间表，你面临着进入ICU（重症监护病房）的风险。

“996.ICU”项目旨在创造一个主张保护劳动者权益的开源（开放源代码）软件许可证。目前，反996许可证还处于起草阶段，该许可证的目的是阻止相关公司使用许可证下的软件或代码。

此前，“996.ICU”项目的发起人曾写邮件给Python之父Guido van Rossum，希望能修改Python的授权许可证，停止向实行“996工作制”以及其他违反加班制度的公司授权，强逼这些公司进行让步（注：Python是一种计算机程序设计语言）。

Guido van Rossum未明确回复是否会这么做，但是他在社交平台发声称，“996工作制”是不人道的。
