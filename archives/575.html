Google Blogger使用技巧

2006-7-27 16:34:55 | 作者: 月光 | 分类: 互联网络 | 评论: 42 | 浏览:

Blogger是Google提供的免费博客服务，提供中文界面，是一个很成熟的中文博客发布平台。

Blogger一个突出的特点就是简洁但功能强大，没有多余而花哨的功能，必要的功能一个都不差。Bloger自由性最大的地方在于其模板可以自定义，也就是说你可以修改模板里的任何内容，包括Google的广告，这给那些懂Html和CSS的Blogger提供了很大的自由度。Blogger默认把用户的网志发布到免费提供的Blogspot.com主机上。可惜的是Blogspot.com从中国是无法访问。好在Blogger.com提供了一种很独特的服务，可以将博客的静态页面通过FTP发布到用户选择的服务器上。

文章置顶

修改blogger的布局，增加一个小工具“精选博文”，在精选博文小工具里选择置顶的文章，即可将该文置顶。另一个方法是编辑文章，将文章日期修改为今天。

标签菜单

修改blogger的布局，在“跨列”里，增加一个小工具“标签”，点击主题背景，自定义，修改CSS，将

.tabs-inner .widget li a {

修改为

.tabs-inner .widget li span {

删除标签提示

删除标签列表里的“显示标签为‘某某’的博文。显示所有博文。”这一段文字，点击主题背景，自定义，修改CSS，添加一行

.status-msg-wrap {display:none; }

修改标签提示样式

修改样式，修改status-msg-wrap的CSS即可，在自定义CSS中加入类似如下的语句，CSS样式可自己调整。

.status-msg-wrap {
width: 100%;
margin: 0 auto;
position: relative;
}

修改标签提示内容

修改文字内容，编辑模板HTML代码，搜索“<data:navMessage/>”这一行，找到后，将其替换为自己想要的文字即可，如果要显示标签变量，使用“<data:blog.searchLabel/>”这个即可。

顶部标签菜单区域增加背景色

增加自定义CSS，内容为：

.tabs-inner {
  padding: 0;
  background-color:#6baa4a;
}

正文区和侧面小工具栏之间增加分隔竖线

添加自定义CSS，代码如下：

.fauxcolumn-right-outer {
margin: 0;
padding:6px;
border-left: 1px solid #CCCCCC;
}

border-left: 1px solid #CCCCCC; 其中solid 指要加一条实线。如果你想加一条虚线， 把solid 改成dotted即可（注意solid 和#之间有一个空格）。

在列表页里只显示文章的标题

使用 Blogger 自带缩略显示命令 <!--more-->，在文章开头批量添加这个命令。

删除“Read More”文本和链接

编辑模板文件，搜索“jump-link”，将其下面的一行如下内容删除即可。

<a expr:href='data:post.url + &quot;#more&quot;' expr:title='data:post.title'><data:post.jumpText/></a>

将Blogger较新的文章／较旧的文章改为上一页／下一页

编辑模板文件，搜索<data：newerPageTitle/>及<data：olderPageTitle/>。

将其改为上一页与下一页（可以个人需求命名），最后保存。

Blogger的限制

博客数量 – 每个帐户 100 个博客。

团队成员（可以写博客的人）——每个博客 100 个成员。

页面大小 – 单个页面（博客的主页或存档页面）限制为 1 MB。

标签数量 – 每个博客 5000 个唯一标签，每个帖子 20 个唯一标签（最多 200 个字符）。

图片数量 – 最多 1 GB 的总存储空间。

帖子数量 - 一个博客中可以拥有的帖子数量没有限制。但是，每天最多可以创建或发布 100 个帖子。

导入限制 - 我自己尝试，每天通过导入的方式最多可以每个账户导入 240 篇帖子左右，不分博客，账户共享这个额度。此外单个 IP 地址每天上传容量限制约为 12M 左右，如果帖子数量没有超标，则更换 IP 地址可以继续上传。

通过电子邮件发布日志

在Blogger中写日志麻烦？告诉你一个技巧，你可以不登录Blogger网站，只要发送一封电子邮件就可以发表文章了。

具体的方法是：登陆你的Blogger帐号，进入控制面板，更改设置，在“电子邮件”中，在Mail-to-Blogger地址中可以自定义一个邮件地址，发送到此地址的邮件会自动张贴，BlogSend地址是另外一个电子邮件地址，只要一发布文章，系统会将其邮寄文章到此地址。

这里再介绍一个小技巧，就是在更新Blogger的同时也更新MSN Space。因为MSN Space也是支持邮件发布的，因此将Blogger发布后发送邮件的BlogSend地址修改为MSN Space的发布邮件地址，这样在Blogger上发布一篇文章后，系统就会自动将文章内容发送到Msn Spaces里，这样就同时更新了两个博客。

有一点值得注意的是，Blogger默认的编码是UTF-8编码，因此发送邮件的时候要将邮件编码设置为UTF-8的格式，建议登陆Gmail发送邮件。一来GMail默认就是UTF-8格式的，编码全兼容，二来GMail支持自动保存功能，不怕电脑死机后丢失文章，三来GMail还可以自动备份发出去的文章，以免文章丢失。

添加Google Adsense广告

Google Blogger用户可以很快捷方便地申请加入Google Adsense广告服务。Google本身也推荐博客们使用Blogger的广告来为自己和Google赚钱。
